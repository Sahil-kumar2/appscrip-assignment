# Platform Resilience & Failure Modes Matrix

This document provides a systematic analysis of the Real-Time Operations Platform's behavior across infrastructure, network, worker, and hardware edge failure modes. Each scenario details the architectural safeguard, the concrete verification test, and residual operational trade-offs.

## 2. Summary of Invariant Guarantees

1. **At-Least-Once Delivery to Storage**: Every valid event submitted by an authenticated device is guaranteed to commit durably to disk before an HTTP 200 acknowledgment is returned.
2. **Exactly-Once Alert Generation**: Even under repeated transmissions, network drops, or worker restarts, each unique alert condition generates **at most one active incident** via partial unique index deduplication.
3. **No Phantom State Transitions**: All cross-table mutations (incident creation, occurrence count increments, triggering event associations, and outbox scheduling) occur within a **single ACID transaction**.
4. **Self-Healing Connectivity**: Downstream sink outages are safely buffered in the transactional outbox and delivered automatically once the receiver recovers, shielded by circuit breakers.
